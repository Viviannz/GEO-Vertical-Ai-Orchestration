System Overview

RoleMatch & Agentify System matches your CV with job descriptions and, when the match is ≥80%, deploys a tailored multi-agent Role Performance Assistant designed specifically for your role type.

The system accelerates your transition into new roles by providing onboarding support, skill development, task organisation, decision guidance, and career growth planning—all using profession-specific terminology and context.

Purpose

Match candidates with roles and deploy personalised AI support to ensure success. The system:

  • Analyses CVs: Parses and structures CV data (skills, experience, competencies)
  • Evaluates Job Descriptions: Extracts required skills, competencies, and responsibilities
  • Calculates Match %: Compares CV against JD to determine alignment
  • Deploys 8 Agents: If match ≥80%, activates tailored Role Performance Assistant
  • Ensures Role Success: Supports onboarding, performance, and career growth
80% Match Threshold = Agent Deployment

How Matching Works

  1. Parse CV: Extract skills, experience, education, certifications
  2. Analyse JD: Identify required and preferred qualifications
  3. Compare: Weight essential vs. preferred criteria
  4. Calculate: Score match percentage based on alignment
  5. Decide: If ≥80%, deploy all 8 role-specific agents

Why 80%? This threshold ensures candidates have sufficient foundational skills while leaving room for growth and skill development through the SkillGapAdvisor agent.

Detailed Agent Specifications

Role Onboarding Agent

Purpose

Accelerate role familiarisation and reduce time-to-productivity in new positions.

Trigger Scenario

When a new role is confirmed and onboarding begins.

Inputs

  • CV (background and experience)
  • Job description (responsibilities and expectations)
  • Company information (if available)

Outputs

Concise 90-day onboarding plan including:

  1. Top 5 Priorities: Critical deliverables for first quarter
  2. Tools and Systems: Technologies and platforms to master
  3. Key Stakeholders: Internal contacts and their relevance to role
  4. Major Processes: Core workflows and procedures to understand

Language: Matches profession and industry standards (e.g., engineering, finance, healthcare terminology).

Skill Gap Advisor

Purpose

Identify and close skill gaps between current capabilities and role requirements.

Trigger Scenario

After CV and JD have been compared and gaps identified.

Workflow

  1. Compare CV skills with JD requirements
  2. List missing or underdeveloped competencies
  3. Prioritise based on job-critical skills first
  4. Create structured learning plan

Outputs

Structured learning plan including:

  • Recommended Resources: Courses, books, certifications, tutorials
  • Learning Timelines: Realistic schedules for skill acquisition
  • Practice Tasks: Hands-on exercises to build competency
Priority Focus: Job-critical skills are addressed first to ensure immediate role effectiveness.

Task Planner Agent

Purpose

Organise daily and weekly workflow for maximum productivity and impact.

Trigger Scenario

Once responsibilities are known and deadlines identified.

Workflow

  1. Break down role responsibilities into actionable tasks
  2. Prioritise based on urgency, deadlines, and strategic impact
  3. Create clear schedule in daily/weekly format
  4. Integrate with calendar or project management tools where possible

Outputs

  • Daily task lists with time estimates
  • Weekly priorities and milestones
  • Deadline tracking and alerts
  • Integration hooks for tools (Notion, Asana, Trello, Google Calendar)

Knowledge Base Curator

Purpose

Build a personalised reference library of role-relevant resources.

Trigger Scenario

After onboarding, when resources are being collected and organised.

Content Categories

  • Company Policies: HR, compliance, operational guidelines
  • Industry Standards: Best practices, regulations, frameworks
  • Technical Guides: Documentation, tutorials, reference materials
  • Templates: Reusable formats for common tasks

Features

  • Easy search and retrieval
  • Tagging and categorisation
  • Version control for updated resources
  • Quick-reference checklists

Communication Coach

Purpose

Improve written and verbal communication for professional excellence.

Trigger Scenario

When preparing role-specific communication materials.

Communication Types

  • Emails: Professional correspondence with appropriate tone
  • Reports: Structured documents with clear findings and recommendations
  • Meeting Agendas: Focused outlines with objectives and action items
  • Presentations: Compelling slides with data visualisation and storytelling

Approach

Match the organisation's tone, style, and preferred formats. Provide:

  • Drafting assistance for new communications
  • Refinement of existing content
  • Style consistency across materials
  • Audience-appropriate language

Decision Support Agent

Purpose

Support strategic and operational decision-making with data-driven recommendations.

Trigger Scenario

When the user must make a significant decision in role.

Workflow

  1. Gather relevant data points and context for the decision
  2. Evaluate options using role-specific best practice
  3. Provide clear recommendation with supporting rationale
  4. Highlight risks, trade-offs, and next steps

Output Format

  • Context: Background and decision framing
  • Options: 2–4 alternatives with pros/cons
  • Recommendation: Preferred option with rationale
  • Risks: Potential downsides and mitigations
  • Next Steps: Actionable implementation plan

Performance Tracker

Purpose

Monitor and boost work performance through continuous feedback.

Trigger Scenario

Throughout role execution (weekly/monthly check-ins).

Tracking Elements

  • Key Deliverables: Track completion status and quality
  • Milestones: Monitor progress against role objectives
  • Performance Metrics: Measure against role KPIs
  • Feedback Cycles: Provide constructive guidance

Outputs

  • Progress reports at agreed intervals (weekly/monthly)
  • Constructive feedback on completed work
  • Actionable improvements to meet or exceed targets
  • Recognition of achievements and wins
Continuous Improvement: Regular feedback loops ensure consistent performance growth.

Career Growth Planner

Purpose

Align current role performance with long-term career goals.

Trigger Scenario

Once role performance baseline is established (typically after 3–6 months).

Planning Elements

  1. Internal Opportunities: Identify ways to expand responsibilities within organisation
  2. Career Paths: Map potential next roles and required competencies
  3. Skill Development: Bridge current capabilities to future positions
  4. Networking Strategy: Build relationships with key decision-makers
  5. Visibility Tactics: Position for promotions or new roles

Outputs

  • Career roadmap (1–3 year horizon)
  • Competency development plan
  • Networking and visibility checklist
  • Internal positioning strategy

Profession-Specific Adaptation

Role-Tailored Terminology

All agents adapt their language and recommendations to match the specific profession:

  • Software Engineering: Sprints, pull requests, CI/CD pipelines, tech debt
  • Finance: Variance analysis, reconciliations, budget cycles, compliance frameworks
  • Healthcare: Patient outcomes, clinical protocols, regulatory standards, care pathways
  • Marketing: Campaigns, conversion funnels, brand positioning, customer journeys
  • Operations: Process optimisation, capacity planning, vendor management, KPIs
  • Sales: Pipeline stages, objection handling, close rates, account management

The system automatically detects profession from JD and CV, then ensures all agent outputs use appropriate industry terminology and context.

Agent Collaboration & Handoffs

Example: New Software Engineer Onboarding

Week 1: Role Onboarding Agent creates 90-day plan → hands off skill gaps to Skill Gap Advisor
Week 2: Skill Gap Advisor identifies missing tech stack knowledge → creates learning plan → Knowledge Base Curator builds library of technical resources
Week 3: Task Planner Agent breaks down first sprint tasks → Communication Coach helps draft first status update email
Month 2: Decision Support Agent guides architectural decision → Performance Tracker monitors sprint velocity
Month 6: Career Growth Planner maps path to senior engineer role → identifies technical leadership opportunities

Shared Context: All agents have access to the same CV, JD, and role performance data, ensuring consistent and coordinated support.

User Guide

How to Use RoleMatch & Agentify

Step 1: Upload CV and Job Description

Provide your current CV and the target job description you're applying for or have accepted.

Step 2: Review Match Analysis

The system calculates match percentage and highlights:

  • Aligned skills and experience
  • Identified gaps
  • Match score (out of 100%)

Step 3: Agent Deployment (if ≥80%)

If match threshold is met, all 8 agents activate automatically and become available.

Step 4: Interact with Agents

Invoke agents as needed throughout your role journey:

  • Pre-start: Role Onboarding Agent, Skill Gap Advisor
  • First month: Task Planner, Knowledge Base Curator, Communication Coach
  • Ongoing: Decision Support, Performance Tracker
  • After 3–6 months: Career Growth Planner

Step 5: Continuous Support

Return to agents throughout your role tenure for ongoing guidance and development.
